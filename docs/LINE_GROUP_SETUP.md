# เชื่อมกลุ่ม LINE พนักงาน

ฟีเจอร์นี้ให้ Owner กดส่งสรุปห้องพร้อมรับเข้ากลุ่มเอง ข้อความจากบอทไม่มีชื่อลูกค้า เบอร์โทร ยอดเงิน หรือรายละเอียดการจอง บอทไม่อ่านข้อความสนทนาอื่นเพื่อนำเข้าระบบ

## สิ่งที่ต้องเตรียม

1. ใช้ LINE Official Account ที่มี Messaging API channel และสิทธิ์จัดการ LINE Developers
2. ใน Messaging API เปิด **Allow bot to join group chats** และ **Use webhook** แล้วเชิญ OA เข้ากลุ่มพนักงาน (LINE อนุญาต OA ได้หนึ่งบัญชีต่อกลุ่ม)
3. ตั้ง Webhook URL เป็น `https://<โดเมนแอป>/api/line-webhook` และกด Verify ใน LINE Developers
4. ตั้งค่าเซิร์ฟเวอร์เท่านั้น: `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_STAFF_URL=https://<โดเมนแอป>/?staff=1` และ `FIREBASE_SERVICE_ACCOUNT_JSON` ที่ระบบ API การจองใช้อยู่แล้ว ห้ามใส่ค่าเหล่านี้ในตัวแปร `VITE_*` หรือส่งในแชต

`LINE_STAFF_URL` ต้องเป็น HTTPS ที่เปิดได้จากโทรศัพท์จริง ลิงก์ `127.0.0.1` ของตัวทดลองใช้กับกลุ่มไม่ได้

## ผูกกลุ่มและส่ง

1. Owner เข้าแอปด้วย PIN ของตนเอง แล้วเปิด **เชื่อมกลุ่ม / ส่งสรุป**
2. กด **สร้างรหัสเชื่อมกลุ่ม** รหัสมีอายุ 10 นาที
3. ส่งข้อความ `/เชื่อม <รหัส>` ในกลุ่มที่มี OA แล้วกด **ตรวจสถานะอีกครั้ง** ในแอป
4. ตรวจตัวอย่างข้อความที่ไม่มีข้อมูลลูกค้า แล้วกด **ส่งสรุปเข้ากลุ่ม LINE** หนึ่งครั้ง ตรวจข้อความในกลุ่มก่อนกดซ้ำหากเครือข่ายขัดข้อง

ข้อความ Webhook ถูกตรวจ `x-line-signature` ก่อนประมวลผล รหัสเชื่อมกลุ่มเก็บเป็น hash และใช้ได้ครั้งเดียว เฉพาะ Owner ที่ล็อกอินเท่านั้นที่สร้างรหัสและสั่งส่งได้ การส่งใช้ Messaging API จากเซิร์ฟเวอร์; โหมด Emulator ปฏิเสธการส่งออก LINE เสมอ

การติดตั้งค่าเซิร์ฟเวอร์, เปิด Webhook, เชิญ OA, push/deploy และส่งข้อความจริงเป็นขั้นตอนภายนอก ต้องทำหลังตรวจแอปและได้รับอนุญาตสำหรับเป้าหมายที่ระบุ
